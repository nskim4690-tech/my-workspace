## 이 작업대는

**젠트리**와 **가족**의 자원을 한곳에서 관리하고, Claude(AI)와 함께 최적화하는 개인용 **데이터베이스 + 대시보드**입니다.

### 3가지 핵심
1. **목공방** — 제2의 인생을 만들기
2. **월1000** — 평생 경제적 자유 달성
3. **가족** — 딸, 아들, 배우자의 시간과 자원 최적화
