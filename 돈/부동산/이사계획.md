## 4. 계약 전 안전 점검 (깡통전세 예방)

- ⬜ **등기부등본** 떼서 확인 — 근저당(융자) 얼마인지
- ⬜ **전세금 + 근저당 합계 < 매매시세 × 80%** 인가?
- ⬜ 건축물대장 — 불법건축물·용도 확인 (근생빌라 = 전세대출·보증 거절)
- ⬜ 집주인 **국세·지방세 완납증명서** 요구 (체납 있으면 경매 시 세금이 먼저 가져감)
- ⬜ 계약서에 **"잔금일 다음날까지 근저당 설정 금지"** 특약
- ⬜ 계약금은 **등기부상 소유자 본인 계좌**로만 송금
- ⬜ **전세보증금반환보증** 가입 가능한 물건인지 미리 확인 (HUG/HF/SGI)
- ⬜ 잔금일 **당일 전입신고 + 확정일자**
- ⬜ 잔금일 아침에 **등기부등본 다시 한 번** 확인
