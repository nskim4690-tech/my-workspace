## 막힌 부분
- **카카오톡 발송(플레이MCP)**: 이 세션(Claude Code CLI)에서 도구가 검색되지 않음.
  사용자가 "Claude Cowork" 커스터마이즈 메뉴에서 연결했다고 했으나, 클라우드 예약 작업(routine) 생성 시
  연결 가능한 MCP 커넥터 목록에도 아직 뜨지 않음. https://claude.ai/customize/connectors 에서
  연결 상태 재확인 필요.
