# 17장 · 목재 구매 (상세)

## 1. 제재율(수율)과 구매 단가의 관계

- **제재율(%) = 실사용 가능 목재 부피 ÷ 원목 부피 × 100** (13장 참고)
- 수율이 낮은 원목(옹이 많음, 굽음, 지름 작음)일수록 판재 단가는 올라감 — 원목 등급이 최종 판재 가격에 직결
- **구매 단위 이해**: 재재목은 지역·유통망에 따라 단위가 다름(예: 재(才, 1치×1치×12자 기준의 한국 전통 단위), 才積, BF/보드피트(1"×12"×12"), m³ 등) — 견적 비교 시 단위를 반드시 통일해서 환산할 것

## 2. 구매처별 특징

| 구매처 | 장점 | 단점 | 적합한 경우 |
|---|---|---|---|
| **지역 제재소** | 대량 구매 시 단가 유리, 원하는 두께로 주문 제재(맞춤 제재) 가능 | 최소 주문 수량이 있을 수 있음, 건조 상태가 제각각일 수 있음 | 공방 운영, 대형 프로젝트 |
| **목공용 소매점** | 소량 구매 가능, 다양한 수종 비교, 이미 건조·대패된 상태로 바로 사용 가능 | 단가가 상대적으로 높음 | 개인 작업, 소품 제작 |
| **온라인 구매** | 편리함, 넓은 선택지, 가격 비교 용이 | 함수율·결함 상태를 직접 확인 불가, 배송 중 손상 위험 | 규격화된 부재(합판, 각재 등) 구매 |
| **경매/원목시장** | 원목 상태에서 저렴하게 대량 확보 가능 | 안목(등급 판별 능력) 필요, 개인 건조 부담 | 숙련자, 장기 재고 운용 가능한 경우 |

## 3. 구매 시 체크포인트 (현장 검수 체크리스트)

- [ ] **함수율 확인**: 휴대용 함수율계로 실측 — 용도에 맞는 범위인지(가구재는 통상 8~12%)
- [ ] **뒤틀림 확인**: 판재를 눈높이로 들어 활모양(bow)·옆휨(crook)·비틀림(twist) 육안 점검
- [ ] **갈라짐·할렬 확인**: 단면(마구리)에 방사형 균열이 있는지 — 내부까지 이어졌는지 두드려 소리로도 판단 가능
- [ ] **옹이 위치·크기 확인**: 최종 재단 계획과 겹치는지 미리 표시
- [ ] **변색·부후 흔적 확인**: 곰팡이 얼룩, 물러짐, 벌레 구멍(개나무좀 흔적) 여부
- [ ] **등급 표기 확인**: 구조재라면 등급 스탬프(수종그룹·등급·함수율·등급기관) 확인
- [ ] **결 방향·제재 방식 확인**: 정목/판목 여부가 용도에 맞는지(13장)

## 4. 구매 후 관리로 이어지는 흐름

1. 구매 즉시 함수율 기록
2. 작업 전까지 8장의 스티킹 방식으로 보관해 추가 변형 방지
3. 가공 직전 재측정 → 목표 함수율 도달 확인 후 재단

## 5. 원가 절감을 위한 실무 팁

- 긴 부재가 필요 없다면 **단재(off-cut, 자투리목)** 코너를 활용해 단가 절감
- 옹이·변색이 있는 부분을 감안해 **여유 길이(보통 10~15%)**를 두고 주문해 재단 손실에 대비
- 동일 수종이라도 산지·재배 조건에 따라 등급·가격 편차가 크므로 여러 공급처 비교 견적이 유리
