# 8장 · 목재 건조 (상세)

## 1. 건조의 목적

1. 치수 안정 (뒤틀림·갈라짐 방지)
2. 강도·강성 증가 (FSP 이하에서 함수율↓ → 강도↑, 6장 참고)
3. 접착·도장 성능 향상 (고함수율 상태에서는 접착제 경화 불량, 도막 들뜸 발생)
4. 부후균·곤충 피해 예방 (함수율 20% 미만 유지)
5. 무게 절감 → 운반·시공 효율

## 2. 건조 방식 비교

| 구분 | 천연건조(Air-drying) | 인공건조(Kiln-drying) |
|---|---|---|
| 원리 | 그늘·통풍으로 자연 증발 | 건조실에서 온도·습도·풍속을 강제 제어 |
| 소요 기간 | 수개월~수년(두께·수종에 따라) | 며칠~수 주 |
| 도달 함수율 | 지역 평형함수율 수준(약 12~18%)까지만 가능 | 목표 함수율(6~12% 등)까지 자유롭게 조절 |
| 비용 | 낮음(부지·시간 필요) | 설비·에너지 비용 발생 |
| 품질 균일성 | 날씨 영향 커서 편차 발생 | 스케줄 관리로 균일한 품질 확보 가능 |

## 3. 건조는 어떻게 이루어지나 — 건조 스케줄 개념

- **건조 스케줄**: 함수율 구간별로 건조실의 **건구온도·습구온도(또는 상대습도)**를 단계적으로 조절하는 계획표
- 일반적 진행 순서
  1. **초기 가열(초기증기처리)**: 표면이 급격히 마르지 않도록 높은 습도에서 예열
  2. **주 건조 단계**: 함수율이 낮아짐에 따라 온도를 서서히 올리고 습도를 낮춰 건조 속도를 유지
  3. **평형화(Equalizing)**: 부재 간, 부재 내(표면-내부) 함수율 편차를 줄이는 단계
  4. **컨디셔닝(Conditioning)**: 건조응력(내부 응력)을 풀어주기 위해 일시적으로 습도를 높이는 마무리 단계
- **왜 급하게 말리면 안 되는가**: 표면이 먼저 마르며 수축하는데 내부는 아직 젖어있어 수축하지 않으면, 표면에 **인장응력**이 걸려 균열이 생김(표면균열) — 심하면 내부에 반대 응력이 남아 절단 시 갈라지는 **내부응력(케이스 하드닝, Case hardening)** 문제로 이어짐

## 4. 대표적인 건조 결함

| 결함 | 원인 |
|---|---|
| 표면균열(Surface check) | 급속 건조로 표면-내부 수축 속도 차이 발생 |
| 내부균열(Honeycombing) | 케이스 하드닝 상태에서 내부가 나중에 수축하며 내부에서 갈라짐 |
| 케이스 하드닝 | 표면 대비 내부에 남은 잔류응력 — 절단 시 부재가 오므라들거나 벌어짐으로 확인 |
| 붕괴(Collapse) | 일부 수종에서 세포가 통째로 찌그러짐 — 표면이 울퉁불퉁해짐 |
| 뒤틀림(Warp) | 불균일 수축(7장) — 활모양(bow), 옆휨(crook), 비틀림(twist), 컵핑(cup) |

## 5. 자가 건조 시 유의점 (현장/개인 작업장 기준)

- 그늘지고 통풍이 잘 되는 곳에 적재(직사광선·비 노출 금지)
- 스티킹(간격재) 두께는 보통 **15~25mm** 내외로 균일하게 사용, 스티커 간격은 부재 처짐이 없도록 60cm 내외로 배치
- 초기 몇 주는 급속 건조를 막기 위해 상부·측면을 얇게 덮어 통풍은 확보하되 직접적인 바람·햇빛은 차단
- 두꺼운 목재일수록 건조 기간이 두께의 제곱에 비례해 늘어나는 경향 — 서두르지 않는 것이 갈라짐 예방의 핵심

## 6. 제재목 보관 (스티킹)

1. **받침대**로 지면과 최소 15~20cm 이상 띄워 지면 습기 차단
2. 판재 사이 **스티커(간격재)**를 수직으로 일직선이 되도록 배치(어긋나면 처짐·변형 유발)
3. 최상단에 **하중(누름돌·판)**을 얹어 건조 중 뒤틀림 억제
4. 전체를 **덮개**로 씌우되 옆면은 통풍이 되도록 개방
5. 정기적으로 함수율계로 층별 함수율 편차 확인
