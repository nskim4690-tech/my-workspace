# 7장 · 목재 치수변화와 대처법 (상세)

## 1. 방향별 수축률 (생재 → 전건 기준, 총 수축률 참고치)

| 방향 | 총 수축률(대략) | 비고 |
|---|---|---|
| **길이(섬유)방향** | 약 **0.1~0.3%** | 거의 무시할 수준(이상재 제외) |
| **방사방향** | 약 **3~6%** | 방사조직이 수축을 억제하는 역할 |
| **접선방향** | 약 **6~12%** | 가장 큰 변화 — 방사방향의 약 **1.5~2.0배** |

- **T/R비(접선/방사 수축비)**: 이 비율이 클수록 건조 중 뒤틀림 경향이 큰 수종 — 수종 선택 시 참고 지표
- **수축률 추정 공식(단순화)**: 함수율 1%당 수축률 ≈ 총 수축률 ÷ (FSP − 0)  → 예를 들어 접선방향 총수축 8%, FSP 28%라면 함수율 1% 변화당 약 0.29%씩 치수가 변한다고 근사할 수 있음(실제로는 완전한 선형은 아님)

## 2. 방향별 차이가 생기는 이유

- 세포가 **길이 방향으로 길게 배열**되어 있어 축방향 수축은 거의 없음
- **방사조직**이 방사방향의 수축을 물리적으로 붙잡아주는 역할을 해서 접선방향보다 수축이 작음
- 나이테 자체가 곡선이므로, **판재를 어떻게 켜느냐(정목/판목)**에 따라 실제 체감 변형 방향이 달라짐(13장 참고)

## 3. 불균일 수축이 만드는 변형 패턴

| 판재 위치(원목 단면 기준) | 변형 형태 |
|---|---|
| 수심 부근(정목에 가까움) | 변형 적음, 비교적 안정 |
| 원목 바깥쪽(판목에 가까움) | **컵핑(cupping)** — 접선방향 수축이 커서 판재가 활처럼 휨 |
| 원목 전체를 통과하는 판재(수심 포함) | 다이아몬드형 변형 |
| 정사각 각재 | 원형 단면이 타원형으로 변형되는 경향 |

## 4. 목재 치수변화 대처법 (7장 후반부)

1. **사전건조(Pre-drying)**: 사용 환경의 EMC(6장 참고)에 맞춰 미리 건조 — 가장 근본적인 대책
2. **수분흡수 제어**: 도장(코팅형·침투형)으로 표면을 덮어 수분 출입 **속도**를 늦춤 (완전 차단은 불가능하다는 점 유의)
3. **기계적 제한**: 프레임 구조, 부동촉(floating tenon), 슬롯 홀(slot hole) 등으로 목재가 움직일 "여유 공간"은 주되 뒤틀리는 방향은 구속
4. **화학적 안정화 처리**: PEG(폴리에틸렌글리콜) 함침 등으로 세포벽 내부를 화학물질로 채워 결합수 자리 자체를 대체 → 수축·팽윤 현상 자체를 줄임(목공예·문화재 보존에서 활용)
5. **설계 단계 대응**:
   - 넓은 판재는 **정목 켜기**를 우선 고려(수축률 낮고 균일)
   - 집성 시 **결 방향을 서로 엇갈리게**(직교) 배치해 전체 수축을 상쇄
   - 상판-프레임 결합부에 **여유 슬롯**을 두어 계절 변화에 따른 움직임 허용(예: 테이블 상판 고정용 버튼/Z클립)
6. **습도 추적**: 습도계로 작업장·보관 환경의 상대습도를 상시 확인
7. **자가 수분측정 장치**: 휴대용 함수율계로 목재 상태를 수시로 점검, 가공 전 목표 함수율(보통 8~12%) 도달 여부 확인

## 5. 실무 체크리스트

- [ ] 가공 전 함수율계로 목표 함수율(용도별 상이) 확인
- [ ] 판재 방향(정목/판목)에 따라 수축 예상 방향 표시해두기
- [ ] 큰 판재는 양면 도장(앞뒤 동일 처리)으로 수분 출입 불균형 방지 — 한쪽만 도장하면 오히려 휘어짐 유발
- [ ] 조립 시 결 방향이 다른 부재끼리는 고정식 대신 유동식 접합 고려
