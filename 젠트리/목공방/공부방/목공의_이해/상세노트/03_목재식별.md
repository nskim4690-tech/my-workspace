# 3장 · 목재 식별 (상세)

## 1. 거시적(육안) 식별 특성

| 특성 | 확인 방법 | 예시 |
|---|---|---|
| 색상 | 심재/변재 색 대비 확인 | 흑단(검정), 파둑(주황), 월넛(짙은 갈색) |
| 향 | 절삭 직후 냄새 | 삼나무(스기 특유향), 히노키(편백향), 시더(방충향) |
| 촉감·질감 | 표면 매끄러움, 유분감 | 티크(기름기), 발사(푸석함) |
| 무게감 | 손으로 든 느낌 → 비중 추정 | |
| 나이테 폭·색 대비 | 조재/만재 대비가 뚜렷한지 | 소나무류는 대비 뚜렷, 삼나무도 대비 큼 |

## 2. 물리적 특성 측정

- **밀도·비중 측정**: 물에 뜨는 정도, 또는 부피·중량 실측으로 비중 계산
- **경도(Hardness)**: 압흔 시험(Janka 경도 등) — 바닥재·계단재 선정 시 실무적으로 중요한 지표
- **강도 추정**: 밀도가 높을수록 대체로 단단하고 가공 시 절삭 저항이 큼

## 3. 목재기술(현미경 식별) — 핵심: 도관 배열

| 유형 | 특징 | 대표 수종 |
|---|---|---|
| **환공재(Ring-porous)** | 나이테 시작(조재) 부분에 큰 도관이 원형으로 띠를 이룸 | 참나무, 느티나무, 물푸레나무, 밤나무 |
| **산공재(Diffuse-porous)** | 도관 크기가 고르고 단면 전체에 균일하게 분포 | 자작나무, 단풍나무(메이플), 벚나무, 오동나무 |
| **반환공재(Semi ring-porous)** | 조재에서 만재로 갈수록 도관 크기가 점차 작아짐(뚜렷한 경계 없음) | 호두나무(월넛), 옻나무 |

- **방사조직 관찰**: 폭이 넓고 발달한 방사조직은 접선단면에서 반점 무늬, 방사단면(정목)에서는 은백색 光沢 무늬(**메디큘러 레이**)로 나타남 — 참나무 정목판의 특징적 무늬가 대표적
- **수지구 유무**: 소나무속(Pinus) 등 일부 침엽수에만 존재 → 침엽수 수종 간 구분에 활용
- **나선비후(Spiral thickening)**: 세포벽 안쪽에 나선형 무늬 — 주목, 마가목 등 일부 수종의 식별 포인트

## 4. 실무 식별 팁 (현장에서 빠르게 구분하기)

1. **무게를 먼저 들어본다** → 비중 대역을 추정 (가벼움: 삼나무/전나무류, 중간: 소나무/자작나무, 무거움: 참나무/티크)
2. **단면의 도관(구멍) 유무**를 본다 → 구멍이 보이면 활엽수, 안 보이면 침엽수
3. **환공재인지 산공재인지** 확인 → 참나무 계열 vs 단풍나무 계열 구분
4. **향을 맡는다** → 침엽수 중 향이 강한 수종(편백, 삼나무)은 즉시 구분 가능
5. **색상·무늬**로 최종 확인 (표준 수종 견본과 대조)
