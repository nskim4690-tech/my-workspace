# 군 복무 ~ 졸업까지 진로 로드맵

인하대학교 컴퓨터공학과 재학 중 입대, 2026년 11월 전역 예정인 학생을 위한
진로 준비 로드맵 PPT와 생성 스크립트.

## 파일 구성

- `build_pptx.py` — python-pptx로 로드맵 PPT(17슬라이드)를 생성하는 스크립트
- `군복무_졸업_로드맵_상세.pptx` — 생성된 최종 결과물

## 내용

- 잔여 복무 ~ 전역 공백기 ~ 2~4학년 학년별 준비 로드맵
- 국내 대표 인턴십 · 채용연계 교육 프로그램 (삼성 인턴, SSAFY, 네이버 부스트캠프,
  카카오테크 부트캠프, 우아한테크코스, SW마에스트로, 42Seoul) — 공식 사이트 링크 포함
- 인턴 · 채용 정보 사이트 모음 (사람인, 잡코리아, 원티드, 링커리어 등) — 링크 포함
- 분야별 상세 (백엔드 / AI·데이터 / 정보보안 / 클라우드·DevOps): 자격증, 필요 역량,
  취업 시 필요한 것, 대표 기업, 신입 초봉 수준, 선호 학력
- 대기업 신입 초봉 스냅샷, 종합 우선순위

연봉·초봉 수치는 2025~2026년 시장 조사 기준 추정치이며 기업·직무·성과급 정책에 따라
실제로는 차이가 클 수 있습니다.

## 재생성 방법

```bash
pip install python-pptx
python build_pptx.py
```

Windows 환경에서 `lxml` 최신 버전이 `DLL load failed` 오류(백신 프로그램이 새로
다운로드된 DLL을 차단하는 경우가 있음)를 낼 경우 `pip install "lxml==5.2.2"`로
낮춰서 설치하면 해결됩니다.
